最小二乘拟合

模型：y = k·x + b（多自变量时为 y = k₁x₁ + k₂x₂ + … + b）。Excel 最后一列为因变量 y，其余数值列为自变量 x，序号列自动排除。
📁 点击上传 Excel 文件
支持 .xlsx / .xls / .csv（读取第一个工作表），也可以直接把文件拖进来
没有数据？下载示例试试：demo-1var.xlsx（单自变量，y ≈ 2.49x + 1.37）　demo-2var.xlsx（双自变量，y = 2x₁ + 3x₂ + 1）

手动输入数据

方式一：在 Excel / WPS 里选中数据区复制，粘贴到下面文本框（支持 Tab / 逗号 / 分号 / 空格分隔，首行可为表头），点「解析到表格」。
方式二：直接在下方表格里逐格填写（最后一列是 y，其余是 x），可随时增删行、列和改表头。序号列同样会被自动排除。
