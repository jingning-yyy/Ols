# OLS 回归工作台

> 在线最小二乘拟合工具：输入 x / y 数据，拟合 y = k·x + b（多自变量时为 y = k₁x₁ + … + b），输出 k、b、R²、RMSE 和「预测值 vs 真实值」对比图。纯前端，计算全部在浏览器本地完成，无后端、不上传数据。
>
> 状态：可用版本（已经过 5 轮系统性测试）｜ 本文档对应 2026-10-26 整理后的 GitHub Pages 站点结构。

## 3. 输入方式与数据识别规则

三种输入方式（界面顶部标签页互斥切换，逻辑在 `setInputMode()`）：**上传文件**（.xlsx/.xls/.csv）、**粘贴文本**（Tab/逗号/分号/空格分隔均可，支持 CRLF、空行、行尾多余分隔符）、**手动表格**（增删行列、改表头）。三种方式走同一条解析管线 `parseAndFit()`。

识别规则：

- **表头**：文件/粘贴时首行含非数值内容则自动识别为表头；手动输入由代码显式传入（`explicitHeader` 参数，此时调用方已把表头行放在 rawRows[0]，管线内会剔除）
- **列角色**：最后一列固定为因变量 y，其余数值列为自变量 x
- **序号列排除（阶梯式回退）**：
  1. 表头匹配 `/^(序号|编号|索引|index|no\.?|id|#)$/i`，或取值恰好为连续整数 1..n → 排除
  2. 若排除后没有任何自变量剩余 → 只按表头名排除
  3. 仍不足 → 全部保留为自变量，并在预览下方给出提示
- **CSV 编码**：先按 UTF-8 严格解码，失败自动回退 GBK（兼容国内 Excel 导出的 CSV）
- **数值校验**：任何参与计算的列存在非数值 → 报错并指明列名、行号、内容

## 4. 算法实现（olsFit）

- 普通最小二乘：构建正规方程 A·θ = b（回归向量 φ = [x₁,…,xₙ, 1]），列主元高斯消元求解
- **求解前按列缩放**：每列除以该列最大绝对值（截距列固定为 1），解出后再除回。目的：消除量纲差异，否则大数值列（如 10⁶ 量级）会让截距列的合法主元被误判为奇异（已踩坑并修复）
- **奇异判定**：消元中主元 ≤ 缩放后矩阵最大绝对值 × 1e-10 → 抛出「自变量线性相关（或数据不足），方程没有唯一解」
- **代码位置**：`index.html` 内 `/* ===== ALGO-START ===== */` 与 `/* ===== ALGO-END ===== */` 标记之间的 `olsFit()`，可整体替换为其他求解实现
- **显示约定**：|系数| < 数据尺度 × 1e-9 的浮点舍入残余按 0 显示（`snap()`）；RMSE 同理；方程负号独立排版（避免出现「+ -5」）

图表规则（`drawFitChart()`）：单自变量按 x 实际值升序排列（蓝点/蓝线真实值，红虚线拟合直线）；多自变量按真实值 y 升序、横轴为位次；n ≤ 8 时横轴每点标刻度；窗口 resize 自动重绘（`lastFit` 缓存结果）。

关键函数：`parseAndFit()`（解析+角色识别+校验+触发计算）、`compute()`（调 olsFit 并渲染）、`renderResult()`（结果与方程排版）、`drawFitChart()`（对比图）、`renderEditor()`（手动输入表格）。

## 5. 测试记录（2026-09-08，5 轮 40+ 检查点）

与 Python 独立实现（正规方程直接解）逐值比对：

- **有效文件 11 组**全部通过：噪声数据、双自变量、序号列、CSV、文本格式数字、中间空行、无表头、1000 行、y 恒定、x 恰为 1..n；误差 ≤ 1e-13
- **错误场景 5 组**提示正确：非数值（含列名/行号）、缺单元格、仅 1 列、数据行过少、严格共线
- **粘贴格式**：Tab/逗号/分号/空格、CRLF、空行、行尾 Tab 全部通过
- **压力测试 8 组**：n=3~500、量级 10⁻⁴~10⁶、负值、多变量精确解误差 1e-13 量级；严格共线抛错、全零列抛错
- **已知边界**：两列自变量近共线（相关系数≈1）时，个别系数在数学上不可辨识（如 x₂≈x₁ 时只能确定 k₁+k₂），任何求解器（含 numpy）都相同，非工具缺陷
